Demo data is simulated in your browser for this page. The real dashboard shows your actual ACC session.

Three hops, no fuss.

Telemetry leaves your PC, passes through a relay, and lands on every connected screen within a tick.

  1. Sim rig

    A client script next to ACC reads telemetry and pushes it over a WebSocket.

  2. Relay on Render

    server.js accepts each message and fans it out to every other connected client.

  3. Browsers

    The same server hosts the dashboard page, so viewers just open one URL.

  4. Instant context

    The relay remembers the last message, so a new viewer sees data immediately instead of waiting for the next tick.
